### About Me

I am a Full Stack Developer focused on building practical, resilient web and mobile applications. My work centers around the TypeScript and JavaScript ecosystems, with an emphasis on end-to-end development using React, Next.js, React Native, and Node.js.

I prioritize clean architecture, maintainable abstractions, and pragmatic solutions over unnecessary complexity. For me, engineering is about shipping reliable software that balances performance, user needs, and readable codebases that teams can easily maintain and scale.

Current areas of focus:
- Developing production-ready web applications with Next.js, React, and modern CSS architectures.
- Engineering cross-platform mobile experiences with React Native.
- Designing backend services and structured REST APIs with Node.js, Express, and relational/document databases.
- Active involvement in open-source projects and continuous technical improvement.
